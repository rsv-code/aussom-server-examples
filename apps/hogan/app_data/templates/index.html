Hogan's Hereos API

About:

Welcome to the Hogan's Heroes fan page API! This API provides a variety of API endpoints about the great Hogan's Heroes show. Images are public domain from CBS Television, Public domain, via Wikimedia Commons. You win some, you lose some.

Definition: Generated OAS Specification for Hogan API
Bruno API Client File: hogan-api-endpoints.yml

Endpoint Info:

All endpoints return application/json unless noted.

GET /

HTML landing page (this page). Rendered with Handlebars from app_data/templates/index.html.

Returns: text/html

GET /show

Top-level facts about the show: title, network, dates, episode/season counts, setting, studio, and premise.

Returns: a JSON object of show-level metadata.

{
  "title": "Hogan's Heroes",
  "network": "CBS",
  "country": "United States",
  "genre": "Military sitcom / war comedy",
  "createdBy": ["Bernard Fein", "Albert S. Ruddy"],
  "premiereDate": "1965-09-17",
  "finaleDate": "1971-04-04",
  "seasons": 6,
  "episodes": 168,
  "runtimeMinutes": 30,
  "setting": "...",
  "premise": "...",
  "studio": "...",
  "pilotFormat": "...",
  "firstSeasonRanking": "..."
}
GET /themesong

Credits and trivia for the show's theme music, the Hogan's Heroes March by Jerry Fielding.

Returns: a JSON object describing the theme song.

{
  "title": "Hogan's Heroes March",
  "composer": "Jerry Fielding",
  "style": "Military march",
  "drumRiffPerformer": "Bob Crane (a former professional drummer)",
  "lyricalVersion": "..."
}
GET /characters

Principal and recurring characters together with the actors who played them, their ranks, nationalities, and roles.

Returns: a JSON array of character objects.

[
  {
    "name": "Col. Robert E. Hogan",
    "actor": "Bob Crane",
    "rank": "Colonel",
    "nationality": "American (U.S. Army Air Forces)",
    "role": "Senior POW officer; mastermind of the sabotage operation..."
  },
  ...
]
GET /quotes

Memorable quotes from the series, each tagged with the speaker.

Returns: a JSON array of quote objects with speaker and quote keys.

[
  {
    "speaker": "Sgt. Schultz",
    "quote": "I know nothing! I see nothing! I hear nothing!"
  },
  ...
]
GET /castreallifetrivia

Real-life facts about the cast (wartime histories, backgrounds, post-show careers).

Returns: a JSON array of trivia strings.

[
  "Werner Klemperer (Klink) was the son of legendary conductor Otto Klemperer...",
  "Robert Clary (LeBeau) was a Holocaust survivor...",
  ...
]
GET /productiontrivia

Production-side trivia: creators, network, awards, sets, and post-show history.

Returns: a JSON array of trivia strings.

[
  "Created by Bernard Fein and Albert S. Ruddy...",
  "168 episodes were produced across six seasons (1965-1971)...",
  ...
]
GET /funfacts

Lighter in-universe and behind-the-scenes oddities that don't fit the production-trivia bucket.

Returns: a JSON array of trivia strings.

[
  "Stalag 13 in the show is named after the real Stalag XIII-C near Hammelburg...",
  "Werner Klemperer's iconic monocle was worn over his actual prescription lens.",
  ...
]
